# 本地调整 Club 界面

双击根目录 `start-club-local.bat`，启动后打开 `https://127.0.0.1:8788/import`。

- 页面和接口都在本机运行，接口复用现有 Club Worker，连接与正式站相同的 Supabase 项目。使用已有账户登录，本地登录与正式站互不共享。
- 修改页面后会实时更新，必要时刷新；无需反复构建或 Push。预览使用本地 HTTPS，自签证书提示只在该本机地址继续。
- 保存导入或修改别名会影响正式数据。仅查看、核对未提交名单不会保存导入。
- 保持启动窗口打开；Ctrl+C 停止两个本地服务。端口已占用时会报错，不会结束其他程序。
- 缓存／临时配置沿用 `scripts/env.ps1` 的可移植目录。无需 Docker，不安装依赖，不自动运行测试、迁移、Push 或部署。

先在本地逐项调整，用户确认后再统一提交并 Push；现有 GitHub Actions 会在相关检查通过后发布正式站。
