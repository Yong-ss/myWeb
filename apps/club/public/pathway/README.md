# Club pathway assets

Six uploaded game icons downscaled to 384×384 WebP with transparency preserved.
Place the `.webp` files in `apps/club/public/pathways/` in your local repository.
Do not use the old original 1920×1920 files in lists; these optimized files are sufficient for small badges and chart legends.

`palette.json` is an initial visual design suggestion, NOT official game-defined hex values.
Ask the coding agent to sample/check contrast on the actual dark theme and use a single shared typed map.

IMPORTANT: `sun.webp` is named 太阳 in the uploaded file, while the current data has 歌颂者.
Confirm that 太阳途径 is the correct visual match for this game entry before making an automatic alias. Do not mutate saved data, labels, player identifiers, or original JSON.

All assets supplied by the user and optimized for web usage.
